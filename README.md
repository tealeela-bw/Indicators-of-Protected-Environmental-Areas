# End-to-End ML Pipeline: Protected Environmental Area Drivers

A quantitative data pipeline and machine learning project evaluating structural drivers of terrestrial and marine protected area designations.

## 📌 Project Overview
* **Data Engineering:** Cleaned, merged, and structured multi-variable spatial and environmental indicators across global datasets.
* **Statistical Modeling:** Performed exploratory data analysis (EDA) and Ordinary Least Squares (OLS) regression modeling.
* **Machine Learning:** Trained classification algorithms to predict protected land designation drivers.

## 🛠️ Tech Stack & Tools
* **Languages:** Python (Pandas, NumPy, Scikit-Learn, Matplotlib/Seaborn), R
* **Methods:** OLS Regression, Predictive Classification, Data Cleaning & Feature Engineering

## 📂 Repository Structure
* `scripts/` — Python data cleaning and ML model execution scripts
* `data/` — Processed environmental indicators
