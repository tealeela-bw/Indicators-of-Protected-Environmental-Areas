# Indicators-of-Protected-Environmental-Areas
# End-to-End ML Pipeline: Protected Environmental Area Drivers

## Project Overview
This repository contains an end-to-end machine learning and data analytics pipeline evaluating the key structural, economic, and geographic drivers of protected terrestrial and marine conservation designations.

## Key Features & Workflow
- **Data Engineering:** Cleaned, merged, and structured multi-variable environmental indicators across spatial datasets.
- **Statistical Modeling:** Performed exploratory data analysis (EDA) and OLS regression modeling to evaluate policy variables.
- **Predictive Analytics:** Trained classification models to predict conservation land designation probabilities.

## Tech Stack & Tools
- **Languages:** Python, R
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib / Seaborn
- **Environment:** Jupyter Notebooks
